# Source Corpora — Acquisition Guide

The raw corpus data is **not included** in this repository because the corpora are proprietary and distributed under separate licenses. You must obtain each corpus independently and place it in the correct directory under `corpus_data/` before running the pipeline.

---

## Corpora

### 1. BAWE — British Academic Written English Corpus

- **Contents:** ~2,500 pieces of student academic writing from UK universities, across 35 disciplines and 4 grade bands
- **Format:** Pre-segmented XML; each sentence is already enclosed in `<s n="N">` tags — **no sentence tokenization needed**
- **License:** Available to UK HE/FE institutions via the Oxford Text Archive; researchers at other institutions should contact the BAWE team
- **Access:** [https://warwick.ac.uk/fac/soc/al/research/collections/bawe/](https://warwick.ac.uk/fac/soc/al/research/collections/bawe/)
- **Place at:** `corpus_data/BAWE/CORPUS_UTF-8/*.xml`

---

### 2. MICUSP — Michigan Corpus of Upper-Level Student Papers

- **Contents:** ~830 papers by advanced undergraduate and graduate students across 16 disciplines at the University of Michigan
- **Format:** Raw HTML-like XML files scraped from the MICUSP website; **sentence tokenization required** (Phase 1)
- **License:** Creative Commons Attribution Non-Commercial Share-Alike 3.0; freely available
- **Access:** [https://micusp.elicorpora.info/](https://micusp.elicorpora.info/)
- **Version used:** `MICUSP_scraped_1.0_20211018` (internal scrape date)
- **Place at:** `corpus_data/MICUSP_scraped_1.0_20211018/raw_xmls/*.xml`
- **Note:** The scraper strips text from `<div class='dynacloud'>` elements. HTML tags (`<p>`, `<i>`, `<b>`, `<u>`, `<br/>`, `<q>`, `<a>`) are removed before Stanza tokenization.

---

### 3. FCE — First Certificate in English Corpus (Cambridge Learner Corpus)

- **Contents:** Scripts from Cambridge English First (FCE) exam candidates; includes error annotation and proficiency metadata
- **Format:** XML, already sentence-segmented — **no sentence tokenization needed**
- **License:** Distributed by Cambridge Assessment English for research purposes
- **Access:** [https://ilexir.co.uk/datasets/index.html](https://ilexir.co.uk/datasets/index.html) (FCE public release)
- **Version used:** `fce-released-dataset` (public release)
- **Place at:** `corpus_data/fce-released-dataset/sentence_segmented_xml/*.xml`
- **Note:** Only **answer2** (the second writing task) is used in this pipeline. The sentence ID format is `{docid}.xml_answer2_{pid}_{sid}`.

---

### 4. TOEFL11 — TOEFL11 Native Language Identification Corpus

- **Contents:** 12,100 essays written by non-native English speakers from 11 L1 backgrounds (Arabic, Chinese, French, German, Hindi, Italian, Japanese, Korean, Spanish, Telugu, Turkish), collected from the TOEFL iBT exam
- **Format:** Plain `.txt` files, one essay per file, pre-tokenised (one token per line with punctuation split); **Stanza tokenization is skipped** (`stanza=False`) — the text is read as-is
- **Metadata CSV required:** `index-training-dev.csv` with columns `file, prompt, l1, score`
- **License:** LDC Corpus LDC2014T06; requires LDC membership/license
- **Access:** [https://catalog.ldc.upenn.edu/LDC2014T06](https://catalog.ldc.upenn.edu/LDC2014T06)
- **Place at:** `corpus_data/TOEFL11 2/NLI_2013_Training_Data-Developement_Data/tokenized/*.txt`
- **Place metadata at:** `corpus_data/TOEFL11 2/NLI_2013_Training_Data-Developement_Data/index-training-dev.csv`

---

### 5. ICNALE — International Corpus Network of Asian Learner English

- **Contents:** Controlled essays by learners of English from 10 Asian countries/regions (China, Hong Kong, Indonesia, Japan, Korea, Pakistan, Philippines, Singapore, Thailand, Taiwan) across proficiency levels A2–B2
- **Format:** Plain `.txt` files with paragraph breaks as double newlines (`\n\n`); **Stanza tokenization required** (Phase 1, `stanza=True`, delimiter=`\n\n`)
- **File pattern:** `*_ORIG.txt` (original, unedited versions)
- **License:** Freely available for research; registration required
- **Access:** [http://language.sakura.ne.jp/icnale/](http://language.sakura.ne.jp/icnale/)
- **Version used:** ICNALE Edited Essays 2.1
- **Place at:** `corpus_data/ICNALE_Edited Essays_2.1/EE_Unmerged_Unclassified/*_ORIG.txt`

## After Placing the Corpora

Run Phase 1 (sentence tokenization) for the three corpora that require it:

```bash
# From 1_corpus_sampling/ as working directory

# MICUSP
python 01_sentence_tokenization/sent_tokenization_MICUSP.py

# TOEFL11
python 01_sentence_tokenization/make_tokenized_xml.py  # set corpus='TOEFL11' in script

# ICNALE
python 01_sentence_tokenization/make_tokenized_xml.py  # set corpus='ICNALE' in script
```

BAWE and FCE are already sentence-segmented and can proceed directly to Phase 2.
